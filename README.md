## Implemented functionalities

- **Info field:** shows a message after each calculation (result less than 100, between 100 and 200, or greater than 200).
- **Unary operations:** square, cube, square root, modulus (absolute value), factorial and power (with a second exponent field).
- **Binary operations:** addition, subtraction, multiplication and division, using the "equal" button. Division by zero is reported as an error.
- **CSV operations:** sum, average, sort, reverse, remove last value, and remove specific values from the list.
- **Error handling:** `validate()` accepts integers, decimals and CSV lists, and shows a specific message for each error (empty field, invalid number, out of range, incomplete list...).
- **Error log:** all errors are recorded and can be downloaded as a `.txt` file.
